### 一键设置（需要 GitHub 写权限）

用已登录的 `gh`：

```bash
gh repo edit maker114/netease-lyric-api \
  --description "Windows 网易云音乐实时歌词/歌曲信息 API：歌手、专辑、封面、进度、歌词；Python/CLI/HTTP/SSE/桌面悬浮窗，只读内存、免登录。" \
  --add-topic netease --add-topic netease-cloud-music --add-topic lyrics \
  --add-topic now-playing --add-topic windows --add-topic python \
  --add-topic http-api --add-topic sse --add-topic obs \
  --add-topic desktop-lyrics --add-topic music --add-topic overlay
```

没有 `gh` 时可直接调用 GitHub API（token 需要 repo / administration 写权限）：

```powershell
$env:GITHUB_TOKEN = "<你的 GitHub token>"
$headers = @{
  Authorization = "Bearer $env:GITHUB_TOKEN"
  Accept = "application/vnd.github+json"
  "X-GitHub-Api-Version" = "2022-11-28"
}
$repo = "maker114/netease-lyric-api"
$desc = "Windows 网易云音乐实时歌词/歌曲信息 API：歌手、专辑、封面、进度、歌词；Python/CLI/HTTP/SSE/桌面悬浮窗，只读内存、免登录。"

Invoke-RestMethod -Method Patch -Uri "https://api.github.com/repos/$repo" `
  -Headers $headers -Body (@{ description = $desc } | ConvertTo-Json)

$topics = @("netease", "netease-cloud-music", "lyrics", "now-playing",
            "windows", "python", "http-api", "sse", "obs",
            "desktop-lyrics", "music", "overlay")
Invoke-RestMethod -Method Put -Uri "https://api.github.com/repos/$repo/topics" `
  -Headers $headers -Body (@{ names = $topics } | ConvertTo-Json)
```

## 2. GitHub Release

`v1.1.0` tag 已推送。当前环境没有 GitHub token，Release 需在网页创建或使用已登录的 `gh`：

```bash
gh release create v1.1.0 dist/netease_lyric_api-1.1.0-py3-none-any.whl \
  --title "netease-lyric-api v1.1.0" \
  --notes-file docs/技术分享-摘要.txt
```

说明：`.github/workflows/release.yml` 已配置为**未来推送 `v*` tag 时自动构建 wheel 并创建 Release**；
v1.1.0 的 tag 早于该工作流，因此需要手动补一次。

## 3. PyPI 发布（可选，收益最大）

截至 2026-11-15，`netease-lyric-api` 在 PyPI **尚未被占用**（404）。发布后即可：

```bash
pip install netease-lyric-api
```

步骤：

```bash
python -m pip install build twine
python -m build --wheel
python -m twine check dist/*
# 需要 PyPI API token
python -m twine upload dist/netease_lyric_api-*.whl
```

发布后建议在 README 顶部加入 PyPI 徽章：

```markdown
[![PyPI](https://img.shields.io/pypi/v/netease-lyric-api)](https://pypi.org/project/netease-lyric-api/)
```
